# Re:Design

Web制作スクールの課題として制作したコーポレートサイトです。
デザインカンプをもとにコーディングを行いました。

## 制作区分
スクール課題

## 担当範囲
- HTML / CSS コーディング
- レスポンシブ対応
- JavaScript / jQuery

## 使用技術
- HTML
- CSS
- JavaScript
- jQuery


## 実装内容
- デザインカンプをもとにしたコーディング
- PC・スマートフォン表示への対応


## 制作で意識したこと
デザインカンプの再現性を意識しながら、PC・スマートフォンそれぞれで
レイアウトが崩れないようレスポンシブ対応を行いました。

共通パーツをクラス化し、CSSの再利用性を意識し、
更新・管理しやすい構成を意識して実装しました。
